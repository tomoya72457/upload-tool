upload-tool

YouTube のチャンネルの持ち主が、自分のチャンネルに動画を上げ、その動画の数字を確かめるための、個人用の道具です。持ち主のパソコンの上で動きます。分析の数字を読む部分だけは、持ち主が用意したクラウドの環境(OpenAI の Codex Cloud)の上でも動きます。動かすのは、持ち主か、持ち主が指示した AI のアシスタントです。

できること

  • 持ち主が許可したチャンネルに、動画・題名・説明・サムネイルを上げ、公開の日時を予約します。
  • 上げた動画の処理と、公開の予約の状態を確かめます。
  • 持ち主が指示した時に、上げた動画の公開の範囲を変えます(非公開から公開へ、など)。
  • 持ち主が指示した時に、上げた動画の題名を変えます(説明・タグ・カテゴリは、今の値のまま送り直します)。
  • 持ち主が指示した時に、上げた動画のサムネイルを、持ち主が選んだ画像に差し替えます。
  • 持ち主が指示した時に、持ち主のチャンネルに再生リストを作り、上げた動画をそこに入れます。同じ動画を2度入れないように、再生リストの名前・公開の範囲と、中の動画を読みます。
  • 許可したチャンネルの名前と ID を読み、上げる先が正しいかを、持ち主が確かめられるようにします。
  • 許可したチャンネルの分析の数字(再生数・視聴時間・平均再生率・高評価・コメント・共有・登録者の増減・視聴維持率・視聴の出どころ・インプレッションとクリック率)を読み、持ち主が動画の出来を確かめられるようにします。読むだけで、変えません。
  • インプレッションとクリック率を読むために、持ち主が指示した時に、YouTube Reporting API で、毎日の報告を作るジョブを作ります(動画ごとの物と、視聴の出どころごとの物の2つ)。

利用規約

この道具は YouTube API サービスを使います。この道具を使う人は、YouTube 利用規約に従うことに同意したものとします。

プライバシーポリシー

  • この道具は YouTube API サービスを使います。Google による情報の扱いは、Google のプライバシーポリシーに書かれています。
  • 使う人は、チャンネルの持ち主1人だけです。ほかの人の情報は集めません。
  • 扱う情報: 持ち主が許可した Google アカウントのチャンネルに動画を上げることと、上げた動画の情報(処理の状態・公開の設定。題名を変える時は、題名・説明・タグ・カテゴリ)と、許可したチャンネルの名前と ID を読むことと、持ち主が指示した時に、上げた動画の公開の設定・題名・サムネイルを変えることと、持ち主が指示した時に、再生リストを作って動画を入れること(そのために、再生リストの名前・ID・公開の範囲と、中の動画の ID を読みます)と、チャンネルの分析の数字を読むことだけです。チャンネルの名前と ID は、上げる先が正しいかを持ち主が確かめるために読みます。分析の数字は、持ち主が動画の出来を比べ、次の動画の作り方を決めるために読みます。
  • 公開の設定を変えるための許可には、動画やコメントの編集と削除も含まれます。この道具は、公開の設定・題名・サムネイルを変えることと、再生リストを作って動画を入れること以外の編集と、削除をしません。
  • 保存: 許可の情報(トークン)は、持ち主のパソコンの中に保存し、外へ送りません(AI のアシスタントにも見せません)。例外は、分析の数字を読むだけの別の許可の情報と、それを使うのに要るこの道具のクライアントの情報です。これは、持ち主が OpenAI の Codex Cloud の保管庫に登録し、そこで動く作業が、分析の数字を読むのに使います。この許可では、動画もチャンネルも変えられません。読んだ動画とチャンネルと再生リストの情報と、分析の数字も、持ち主のパソコンの中に保存します(下の「分析の報告」の物を除きます)。
  • AI のアシスタント: 持ち主は、この道具を、持ち主が使う AI のアシスタント(Anthropic の Claude Code と、OpenAI の Codex と dot)を通しても動かします。その時、道具が画面に出した情報(動画の状態と題名・チャンネルの名前と ID・再生リストの名前と ID と中の動画の ID・分析の数字)は、持ち主の作業を手伝うために、そのアシスタントが読み、それぞれの会社のサービスに送られて処理されます。持ち主は、このアシスタントを、持ち主の代わりに情報を扱う者として認めています。それぞれの会社での扱いは、その会社の規約と方針によります。
  • 分析の報告: 持ち主の指示で、OpenAI の dot が分析の数字を読み、分析と提案を書いて、GitHub にある持ち主の非公開のリポジトリに Pull Request として置きます。分析の数字は、OpenAI と GitHub のサービスの中に残ります。持ち主は、GitHub を、この報告を置く先として、持ち主の代わりに情報を扱う者と認めています。GitHub での扱いは、GitHub の規約と方針によります。ここに書いた者のほかの第三者には渡しません。
  • 分析の数字を残す期間: 持ち主の許可が生きている間、動画の出来を比べるために残します。30日ごとに、許可がまだ生きていることと、数字を残した動画が消されていないことを確かめます。許可が取り消された時や、許可を更新できなくなった時は30日以内に、消された動画の数字は分かった時に、消します。
  • 消すこと: 持ち主は、手元に残した分析の数字を、この道具の forget の命令で、いつでも消せます。持ち主が消すと決めたら、7日以内に消します。GitHub の Pull Request に置いた分析は、持ち主が本文とブランチを消し、残った物は GitHub に頼んで消します。OpenAI のサービスの中の会話と作業の記録は、持ち主が OpenAI の画面から消します(扱いは OpenAI の方針によります)。手元の数字を消しても、YouTube の側のデータは、消えも変わりもしません。YouTube の側のデータを消すには、YouTube のアプリか、それができる道具を使います。
  • 広告は出しません。クッキーは使いません。
  • 許可の取り消し: Google のセキュリティ設定の頁から、いつでも取り消せます。持ち主のパソコンの中の許可の情報を消しても、使えなくなります。Codex Cloud の保管庫に登録した物は、保管庫から消します。
  • 問い合わせ: このリポジトリの Issues へお寄せください。
  • この方針を変える時は、この頁を書き換えます。
