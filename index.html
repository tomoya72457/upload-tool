upload-tool

YouTube のチャンネルの持ち主が、自分のチャンネルに動画を上げるための、個人用の道具です。持ち主のパソコンの上でだけ動きます。

できること

  • 持ち主が許可したチャンネルに、動画・題名・説明・サムネイルを上げ、公開の日時を予約します。
  • 上げた動画の処理と、公開の予約の状態を確かめます。

利用規約

この道具は YouTube API サービスを使います。この道具を使う人は、YouTube 利用規約に従うことに同意したものとします。

プライバシーポリシー

  • この道具は YouTube API サービスを使います。Google による情報の扱いは、Google のプライバシーポリシーに書かれています。
  • 使う人は、チャンネルの持ち主1人だけです。ほかの人の情報は集めません。
  • 扱う情報: 持ち主が許可した Google アカウントのチャンネルに動画を上げることと、上げた動画の情報(処理の状態・公開の設定)を読むことだけです。
  • 保存: 許可の情報(トークン)と、読んだ動画の情報は、持ち主のパソコンの中に保存します。外へ送らず、第三者に渡しません。
  • 広告は出しません。クッキーは使いません。
  • 許可の取り消し: Google のセキュリティ設定の頁から、いつでも取り消せます。持ち主のパソコンの中の許可の情報を消しても、使えなくなります。
  • 問い合わせ: このリポジトリの Issues へお寄せください。
  • この方針を変える時は、この頁を書き換えます。
